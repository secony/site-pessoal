# Site comercial

Abra `index.html` (ou sirva a pasta com qualquer servidor estático / Vercel).

- `js/data.js`: marca, contatos (WhatsApp/e-mail), projetos, depoimentos, FAQ e tecnologias.
- `css/style.css`: tokens de cor e tipografia em `:root`.
- `js/main.js`: renderiza os dados e cuida do menu e das animações.

Pendente: preencher `contact` em `data.js`, trocar os depoimentos de exemplo, definir política de pagamento no FAQ, adicionar `og:image`.
